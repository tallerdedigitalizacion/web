Signs your WordPress needs attention

  • Nobody has updated the plugins or the theme for months (or years).

  • You pay for maintenance but don't know what is being done.
  • There is no recent backup.
  • Nobody knows who has admin access.

FAQ

Common questions

How much does the managed website plan cost?

From €39/month + VAT, with hosting included. The fee depends on the type of site (a corporate site isn't the same as a WooCommerce store) and how many changes you need per month. If the site needs a rescue first, I quote that separately.

My website has been hacked, what do I do?

Don't delete anything and change the admin and hosting passwords. Write to me: first the problem has to be contained and a copy of the current state taken so it can be investigated.

Do I need to pay for WordPress maintenance every month?

If you use WordPress, somebody has to update it. If your site barely changes, it may be more worthwhile to move it to a static site and forget about updates.

Do you work with WooCommerce?

Yes, I review and maintain WooCommerce stores, with extra care around updates.

What if another agency built it?

No problem. I only need admin access and access to the hosting.
